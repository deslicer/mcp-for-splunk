# Configuration Guides

Operator and client guides for connecting to MCP Server for Splunk.

| Guide | Description | Time |
|-------|-------------|------|
| **[HTTP client modes](http-client-modes.md)** | Sessionless vs session-scoped Streamable HTTP | 10 min |
| **[Client configuration](client_configuration.md)** | Headers, env vars, toolsets, multi-tenant patterns | 20 min |

Start with **HTTP client modes** if you are wiring Cursor, Claude Desktop, or
a FastMCP Client to `/mcp`. Use **Client configuration** for the full credential
matrix and `X-MCP-Toolsets` filtering.
